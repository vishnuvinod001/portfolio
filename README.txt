Deploy on Vercel:
1. Replace the GitHub and LinkedIn links in index.html (search for "TODO").
2. Push this folder to a GitHub repo, import it on vercel.com (no build settings needed), or run `npx vercel` here.
3. The LeetCode card calls /api/leetcode (api/leetcode.js). Change the username with the LEETCODE_USERNAME env var if needed.
Local test: `npx vercel dev`
